# Aseprite source pipeline

How Light Show's shipped pixel art is turned back into editable
`.aseprite` documents, edited, and re-exported without hand-slicing
PNGs again. The importer script lives next to this doc at
`scripts/import_sheet.lua`; the art itself ships in
`game/assets/sprites/`.

## Layout

- Companion sheets — `game/assets/sprites/<companion>/<companion>_sheet.png`
  for Lattice, Linka, and Séraphine: 256×384px each (4 columns × 6 rows
  @ 64×64/frame). Row order is fixed by `game/src/waifu/sprite.rs`'s
  `Mood` enum and documented in `docs/ART_STYLE.md`: **Idle, Blush,
  Wink, Pout, Celebrate, Alarmed**. Ondine is the exception: her
  current sheets are `ondine_sheet_fullbody.png` and
  `ondine_sheet_fullbody_mature.png`, with `.aseprite` sources already
  beside them in `game/assets/sprites/ondine/`. Companion sheets are
  regenerated through the Aseprite pipeline scripts in this directory
  (`build_fullbody_aseprite*.lua`).
- Component icons — `game/assets/sprites/components/*.png`: 16 OSP
  component icons (single frame each, 64×64, transparent background),
  generated by `tools/gen_placeholder_art.py`. No rows/tags to slice —
  open these directly in Aseprite rather than through
  `import_sheet.lua`.
- `scripts/import_sheet.lua` — headless Aseprite script that slices a
  companion sheet back into a real multi-frame `.aseprite` document
  with one named tag per mood row.

## Turning a sheet into an editable `.aseprite` document

Parameters arrive via `--script-param`, which must come **before**
`--script` on the command line — params placed after `--script` are
silently dropped, and bare arguments after `--` are treated as files
to open, not as parameters. (Verified 2026-10-11 against Aseprite
1.3.18.6: 24 frames, 6 tags in the correct frame ranges, 0.18s frame
durations.)

```sh
aseprite --script-param 1=game/assets/sprites/seraphine/seraphine_sheet.png \
  --script-param 2=64 --script-param 3=64 \
  --script-param 4=Idle --script-param 5=Blush --script-param 6=Wink \
  --script-param 7=Pout --script-param 8=Celebrate --script-param 9=Alarmed \
  -b --script scripts/import_sheet.lua
```

Repeat for `linka_sheet.png` and `lattice_sheet.png` with the same 6
tag names (the row order is identical across companions by design —
see `docs/ART_STYLE.md`). This writes `<name>_sheet.aseprite` next to
each source PNG, with each frame's duration set to 180ms to match the
in-game animation rate (`Timer::from_seconds(0.18, TimerMode::Repeating)`
in `game/src/waifu/mod.rs`).

## Editing and shipping changes back

Once you have a `.aseprite` document, the
[Diver Neovim Aseprite actions](https://github.com/qompassai/diver/blob/main/lua/games/aseprite/actions.lua)
(`<leader>` menu → "Select Aseprite action" → **Export sprite sheet +
JSON**, or **Export tileset (choose sheet type)** for packed/rows/columns
layouts) re-export a flattened PNG + JSON atlas from inside Neovim via
`aseprite -b <sprite> --sheet out.png --data out.json --format
json-array` — no need to touch the Aseprite GUI's own export dialog.

After re-exporting, copy the refreshed PNG over the matching file under
`game/assets/sprites/<companion>/<companion>_sheet.png` (or
`game/assets/sprites/components/<name>.png`) and re-run
`cargo test --workspace` — `game/src/waifu/mod.rs`'s
`mood_sheet_rows_are_unique_and_within_bounds` and `game/src/board.rs`'s
`every_component_icon_path_actually_exists_under_game_assets` fail
loudly if a mood-row mapping or icon file goes missing/out of range,
instead of silently shipping a broken sheet. Frame pixel dimensions
themselves aren't asserted by an automated test today — visually check
a re-exported sheet against the 256×384/64×64 contract before shipping
it (see `docs/ART_STYLE.md`).

## Palette

Sync the game's palette into Aseprite's color bar so new frames stay
on-model — see `docs/ART_STYLE.md` for the full hex list. Export a
`.gpl` palette from any of the source sheets (Aseprite action **Export
palette (.gpl)**) and sync it via **Sync palette into Aseprite user
config**, which copies it to Aseprite's own palette directory
(`~/.config/aseprite/palettes` on Linux).
