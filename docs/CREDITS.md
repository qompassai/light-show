## Engineering reference data

The dB loss figures used in `crates/osp_sim` (fusion/mechanical splice
loss, UPC/APC connector loss, PLC splitter insertion loss, G.652 fiber
attenuation coefficients, GPON ONT receive sensitivity per ITU-T G.984.2)
are drawn from publicly published industry-standard specifications and
common OSP field practice figures — they are engineering constants, not
copyrightable expression.

  connector, splitter, OLT, ONT, macrobend, water intrusion): filled,
  transparent-background 64x64 sprites generated deterministically by
  `tools/gen_placeholder_art.py` (original tool code, Apache-2.0, no

  source portraits.
  - No proprietary SDK or network call is required at build or run time to

## Procedurally generated audio (no attribution required)

All files below are synthesized from scratch — no samples, no licensed
material — so they carry no attribution burden:

- **SFX** (`game/assets/sfx/*.wav`, 17 files): numpy-synthesized
  square/sine one-shots via `tools/gen_audio_pack.py`.
- **Companion themes** (`game/assets/music/themes/*.ogg`, 8 files):
  per-companion chiptune loops composed against the NES-2A03 engine in
  `tools/gen_chiptune_music.py` (imported, not forked), rendered by
  `tools/gen_audio_pack.py`.
- **Ambience hums** (`game/assets/music/ambience/*.ogg`, 8 files):
  per-companion seamless low-frequency loops (layered sines + filtered
  noise), generated by `tools/gen_audio_pack.py`.

Regenerate everything deterministically with:
`python3 tools/gen_audio_pack.py` (requires numpy, ffmpeg).
