## Honest Retrospective

**What we got right:** The core concept (one companion per access technology) was solid from day one. The color coding by technology stuck.

**What we got wrong:**
- The base sprites were... rough. Serviceable for prototyping, embarrassing in a README.
- We displayed 3MB PNG sprite sheets as if they were animated GIFs. GitHub did its best. It was not enough.
- Linka's original animation had a visible row-seam hop. We fixed it. You're welcome.

**What we learned:** Ship the placeholder, but don't put the placeholder in the README. Also, always check the file extension.
