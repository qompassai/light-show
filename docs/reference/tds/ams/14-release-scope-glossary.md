# Release Scope and Glossary

## Scope

This reference targets Nokia 5520 AMS Release 9.8.3 and the simplex, cluster, and geographically redundant deployments described in the supplied manuals.[cite:3][cite:4][cite:7]

The controlling Nokia documentation remains authoritative for exact prerequisites, supported plug-in combinations, sizing, port matrices, and known defects.[cite:7]

## Boundaries

- The Solution Planning Guide was not supplied, so exact production sizing and full port/bandwidth matrices are not reproduced.
- NE-native CLI is family/release-specific; `ams_ne_cli` transports but does not define it.
- SOAP namespaces and complete envelopes should come from the activated schema documentation.
- Site addresses, credentials, certificates, object names, and paths remain placeholders.
