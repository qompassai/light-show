# Companion level select (2026-10-08)

Flow change (Matt's directive): picking a companion on the picker now opens a per-companion LEVEL SELECT screen (`GameState::LevelSelect`, `game/src/states/level_select.rs`) listing all ten of her levels in track order; choosing one launches it. Before, a card press set `CurrentLevelIndex` to the track start and entered `Playing` directly — later levels were reachable only via Results → Continue.

- The launch contract moved with the flow: `level_select::handle_level_buttons` sets `CurrentLevelIndex`, clears `CurrentScenarioId` (a Field School detour now ends at the launch, not at the pick), and requests `Playing`. `handle_select_buttons` only sets `SelectedCompanion` and requests `LevelSelect`; a trackless companion still stays on the picker with a click.
- No lock rule exists in the game — completion never gated level access — so every row is enterable; the save only annotates. Rows show `CLEARED` + Astra badge names (`SaveData::badges_for` / `astra::badge_names`), the header shows her portrait (`Companion::portrait_path`), name, tagline, and "N of 10 levels cleared". Back button and Escape return to the picker.
- Tests: playthrough harness walks the new screen inside `start_track`; new playthrough tests cover list contents, mid-track launch, back navigation, and save-progress display; unit tests cover the entry derivation (empty / partial / full / other-track saves) and the launch/back/Escape handlers.
