# Struct-size audit + size pins (2026-10-08)

Matt adopted the struct-layout discipline from the "Making Rust structs as small as humanly possible" video for the two hot surfaces (Bevy ECS components iterated per frame; board/signal/level records in Vecs) and asked for it applied to light-show. Measured with a temporary `size_of` probe (not shipped).

- **Verdict: no audited struct shrinks.** The codebase contains zero `repr(C)`/fixed-layout types (repo-wide search), so rustc's default field reordering already packs every audited struct to the floor set by its field multiset. The level/sim records are dominated by 24-byte `String`/`Vec` fields; the rest are already alignment-sorted. Measured (bytes): osp_sim PathNode 32, Edge 32, Component 24, PathGraph 48, LinkBudgetResult 40, EthernetEval 56, CoaxEval 48, WirelessEval 56, Alarm 64, Outage 24; board PillRing 16, PillPop 4, SignalPulse 28; fx ConnectSpark 152, SuccessBurst 200 (frame-handle arrays: 4×24 + Timer 48, 6×24 + Timer 48); level LevelNode 40, LevelEdge 32, ComponentChoice 32, StateLine 56, QuizQuestion 224, SubscriberDef 88, MechanicStates 304 (single instance), LevelDef 1976 (single resource); pill FaceFrame 2.
- **Reductions considered and refused** (would need redesign or unproven narrowing, both outside the directive): `StateLine`'s 56-byte floor is set by `StateId::Coverage(String)` + the feedback `String`; `Alarm.id: u64` and the eval results' `hop_count: usize` have no code-stated narrower bound (`MAX_PATH_HOPS` bounds hop counts in practice, but the eval structs are transient singles, not Vec elements).
- **What landed:** 19 compile-time pins, `const _: () = assert!(std::mem::size_of::<T>() <= N)` with N = measured size, placed beside the hot types — osp_sim graph.rs (PathNode, Edge, PathGraph, LinkBudgetResult, EthernetEval, CoaxEval, WirelessEval), osp_sim component.rs (Component), osp_sim alarm.rs (Alarm), board.rs (PillRing, PillPop, SignalPulse), fx.rs (ConnectSpark, SuccessBurst), level.rs (LevelNode, LevelEdge, ComponentChoice, StateLine), waifu/pill.rs (FaceFrame). A future field/variant that bloats one now fails compilation instead of silently costing cache density.
- **Gates:** workspace keyless suite 806 passed / 0 failed (baseline 806/0 at 4caadae; const assertions add no tests). rustfmt: no flagged hunk touches an added line; pre-existing drift in the touched files left as found. Side observation: under this toolchain `cargo fmt --all -- --check` flags more files than the seven named in the level-select note (also waifu/reactions.rs, waifu/dialogue.rs, salvage.rs, states/warehouse.rs) — a repo-wide fmt pass remains a separate dedicated commit whenever Matt wants it.
