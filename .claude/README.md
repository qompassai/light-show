# Agent skills for light-show

This directory holds vendored agent skills for working on the light-show
repo — the Bevy fiber-optic puzzle game and its store publication. They
are copies of Matt's canonical skills, vendored here so any agent
(Claude Code or opencode) working in this checkout gets the same rules
without extra setup.

Skills: `tiger-style-rust` (all Rust code), `git-wip-guard` (never
destroy uncommitted work), `light-show-publish` (full store-publication
journey: PR merge verification, fastlane metadata, F-Droid recipe,
publish scripts, emulator screenshots, licensed music wiring, primo
build/test gates).
